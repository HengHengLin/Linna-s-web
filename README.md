# Linna 研究实验室（中文版）

保留原版海军蓝、白色及蓝色点缀的 React + Vite 网站。当前优先调试中文版；英文版后续单独实现。金融英语的词汇、表达与输出练习保留英文。

## 本地运行

建议使用 Node.js 22 LTS 或较新的兼容版本，并安装 npm。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址（通常是 http://127.0.0.1:5173/）。

```sh
npm test
npm run build
npm run preview
```

开发与构建前会校验并生成内容。修改 content/public 中的 Markdown 后，开发服务自动重新生成；修改内容脚本、配置或元数据规则后请重启服务。

## 当前功能

- 中文首页、研究列表与详情、全球股指外链、英语实验室、作品集。
- 页面和文章使用独立的 hash 地址，例如 `/#/research/r1`；支持刷新、浏览器前进/后退，静态托管不需要额外配置重写。
- 英语记录支持关键词、主题和日期组合检索。
- 八条演示 Markdown 均明确标注，不代表真实学习经历或已批准研究。
- 行情为 Yahoo Finance 外链，不提供站内实时报价。简报尚无正式内容。
- 交易日志没有身份验证，因此录入、上传及旧日志展示均已禁用；不读取或写入 localStorage，不删除旧记录。

## 内容发布

阅读 [内容编辑说明](docs/CONTENT.zh-CN.md)。只有 content/public 目录中的 Markdown 会被生成至公开内容模块。正式内容必须包含 Linna 确认的审核信息和来源；无效元数据会让构建失败。

任何写入公开 GitHub 仓库的资料都可能公开。不要把未审核观点、真实交易数据、敏感草稿、凭证或雇主保密信息放入这个项目目录。忽略规则只是减少误提交，不提供加密或访问控制。

## 部署与维护

阅读 [部署与回滚说明](docs/DEPLOY.zh-CN.md)。构建输出为 dist，可部署到静态托管服务。源码同步至 GitHub；公开网站已部署到 https://linna-research-lab.luckyaspen8.chatgpt.site。GitHub Actions 执行测试与构建；网页直接同步 GitHub 的公开内容快照。云端定时任务创建因账户 5 个任务上限被拒绝，尚未启用；原本机任务仍在，不能当作云端运行。

## 暂未实现

可靠的私人账户系统、实时行情、云端定时任务启用、英文版、完整社交分享卡片及服务端 SEO。现阶段无需数据库或微服务。自动生成素材需人工审核，不能自行批准后冒充 Linna 的观点。

## 每日学习与选题

英语实验室分为“每日学习记录”与“待学习材料与练习”。学习记录按日期展示一句话总结，点开查看讨论、知识、纠正与练习；首页也有近期学习记录入口。

已创建每日金融英语和每 5 天研究选题的定时安排，具体流程见 [每日学习工作流](docs/LEARNING-WORKFLOW.zh-CN.md)。定时材料不等于已完成学习。你主动把 ChatGPT 总结发到这段聊天后，再据此归档真实学习；当前不能自动读取其他 ChatGPT 聊天。
