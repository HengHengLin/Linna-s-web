## 行情实现、许可与限制

使用 [TradingView 官方 Market Overview 嵌入](https://www.tradingview.com/widget-docs/widgets/watchlists/market-overview/)，保留品牌与来源链接，不抓取网页、导出报价、暴露密钥或引入后端。官方[可用市场说明](https://www.tradingview.com/widget-docs/markets/asia-pacific/)将 SSE、SZSE 和 HSI 列为 **EOD 收盘数据**；免费组件不等于所有市场的实时授权。

已接入上证指数、沪深300、科创50、创业板指、恒生指数。浏览器实际看到五个指数的点位、涨跌点数、涨跌幅与收盘/休市标识。图内曲线与悬浮信息由提供方显示行情日期；本站不以页面加载时间冒充报价时点。美国观察入口仍保留，没有拿 FOREXCOM 差价合约替代现金指数。

刷新由组件数据连接处理，非本站定时抓取。断网时不主动卸载已显示图表，显示连接中断提示；外部脚本失败有明确说明与重新连接按钮。CORS、授权与数据传输由来源组件负责，静态 Pages 无需存放 API 密钥。第三方会接收正常的网络连接信息及页面域名，依据其[官方说明](https://www.tradingview.com/widget-docs/faq/general/)，组件不设置 cookies。

**尚未完全满足的行情要求：**官方[数据 FAQ](https://www.tradingview.com/widget-docs/faq/data/)不提供导出/下载数据的 API。本轮没有取得自行缓存和再次分发报价的权限，因此未实现“关闭页面或刷新后仍恢复最后有效报价”的自有缓存；也不能在本站独立验证、统一列出每个报价的精确时间戳。不能把 iframe 加载成功当作报价实时有效。本轮完成的是可用的授权嵌入 MVP；若需完全自主的表格、日期与断网缓存，应另选明确允许公开展示及缓存的授权数据源，不能用未授权免费端点补齐。

## 私人数据与历史风险

j1.md 及改版前原快照保存在仓库外本地 `Linna-private-archive/2026-10-28/`，目录权限 700、文件 600，未迁移到其他公开仓库。当前发现的是演示学习记录，不是已确认的真实私人日志；当前公开交易页此前也未启用真实录入。

但是 j1 和旧交易代码曾出现在公开 Git 历史，隐藏页面和新构建不能移除历史副本。旧版本曾存在浏览器 localStorage 读写逻辑；本轮没有读取或清理用户浏览器中的原有私有记录，不能据此保证历史不存在敏感内容。

本地改版已阻止 journal 进入公开加载器与 JSON，旧远程快照过渡读取也先排除 journal，再校验和赋值；已确认构建不包含 j1 内容。**正式网站与远程旧快照尚未修改，须批准发布后才会实际下线相应公开资源。**若以后发现真实敏感内容，应先安全备份与撤销泄露凭据，再安排 Git 历史/Pages 产物及缓存清理，并考虑已有克隆和第三方缓存；不得声称删除一个导航就已完成清理。本轮未重写远程历史或 force push。
