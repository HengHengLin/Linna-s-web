# 第二批本地开发记录

复用三个指数专题，新增 IndexAnalysis.jsx 与 AnalysisCharts.jsx。五种 SVG 图表组件：权重排名、近似贡献排序、市场广度、行业风险暴露、等权与市值加权比较；产业链需求暴露使用公司映射卡片展示，真实数据为空时不画估计权重。

新增 src/analysis/math.js、data.js、articles.js，以及 content/outlines/index-analysis-a.md、b.md、c.md。三篇文章保留未经观点审核状态，不进入 content/public 正式发布流。原有文章、图表、公司数据和审核状态不修改。

真实数据完整度：三个指数均未接入完整官方样本与同日权重；ETF 条目、历史权重、公司行动、收益和所有制证据均待核实。realData 以 null 表示缺失，不能将候选公司列表当成完整样本。官方数据接入前必须补充收益区间、交易日历、停牌规则、来源及更新流程，现阶段不开放上传入口。

计算单位：weight、return 均为小数（.1 为 10%），contributionPP 为百分点（.1×.05×100=.5）。HHI 为百分比权重平方和，范围0–10000。完整权重和须为1，不自动归一化。行业和所有制缺失分类进入待核实类别，不能静默删除。近似贡献不等于官方贡献，多期数据需要链式计算和公司行动处理。本版只支持单区间完整样本计算。权重变化需同一权重口径及收益口径的有序两日期。

市场广度使用完整样本作分母，平盘单列；改善/恶化比较前一期上涨家数占比。行业参与度定义为正贡献行业占比。权重股定义为期初权重前十，非权重股为剩余样本，收益差使用两组简单平均；不可与其他定义混用。创新高/低未提供可靠历史时显示待核实。

共同需求映射为多对多，重复公司/需求边拒绝。候选股票权重覆盖不是收入暴露，需求因子可重叠；不得加总成100%或据此推断相关性。四家公司映射均为研究假设，暂无已核验公开业务证据。ETF未来须区分指数、净值和二级价格收益，跟踪误差须保存频率、窗口与年化规则。

来源阅读：2026-10-28 核对 S&P DJI 指数数学方法及上交所 2020-06-19 科创50发布答记者问。后者是历史文件，不能作最新成分权重证据。文章中保留原始URL及资料适用范围。

本轮仅本地开发；不推送、不部署。浏览器此前受工具安全策略限制，移动端和图表交互的实际浏览器验收仍待完成。
